## Быстрый старт

```bash
make venv          # .venv + numpy, matplotlib, pandas, pytest (requirements.txt)
make test          # 36 тестов
make all           # тесты + все эксперименты ЛР1–ЛР3 (~3 мин на 8 ядрах) + подстановка таблиц в отчёты
```

`make lab1`, `make lab2`, `make lab3` — отдельные работы; `JOBS=1` — без параллельности; `SEEDS=0-4 make lab1` — другой набор seed.

## Устройство

- `eaga/` — общее ядро:
  - `core.py` — `CountedFunction` (счётчик вызовов, бюджет, порог) и `run_ga`
    (генерационный цикл с элитизмом и историей);
  - `selection.py` — турнирная и линейная ранговая (SUS) селекция;
  - `rng.py` — генераторы из явного seed;
  - `runner.py` — серии запусков → CSV, статистика;
  - `plotting.py` — графики;
  - `report_include.py` — вставка таблиц из `results/` в отчёты.
- Только `numpy.random.Generator` с явным seed. Глобального состояния нет, и один
  и тот же seed даёт бит-в-бит одинаковые CSV (столбец `time_s`, конечно, отличается).
- Готовые оптимизаторы не используются. Все операторы, ремонт и DP написаны с нуля.
